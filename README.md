# GoWeb

Статический сайт компании GoWeb. Для просмотра откройте `index.html` в браузере. Включите JavaScript для каталога, страниц кейсов и формы. Сайт использует HTML, CSS и чистый JavaScript, а изображения хранятся в проекте.

## Файлы сайта

```text
index.html       Главная, услуги, этапы, компания и контакты
projects.html    Каталог и фильтры
project.html     Шаблон страницы кейса
css/style.css    Оформление и адаптивная сетка
js/main.js       Контакты, меню, форма и вывод кейсов
js/projects.js   Категории и массив кейсов
images/          Главная иллюстрация и макеты интерфейсов
README.md        Инструкция по публикации и редактированию
.nojekyll        Публикация статических файлов напрямую
```

## Публикация на GitHub Pages

### 1. Создайте репозиторий

1. Войдите в свой аккаунт на [GitHub](https://github.com/).
2. Нажмите **+ → New repository**. Введите имя, например `goweb`.
3. Выберите **Public**, чтобы использовать GitHub Pages на бесплатном тарифе.
4. При создании репозитория оставьте добавление README выключенным. Готовый `README.md` уже входит в проект.
5. Нажмите **Create repository**. [Создание репозитория](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository)

### 2. Загрузите файлы в ветку `main`

На странице нового пустого репозитория нажмите **uploading an existing file**. Если в нём уже есть файлы, нажмите **Add file → Upload files**. Перетащите содержимое папки проекта из проводника в область загрузки. Проверьте, что `index.html`, `projects.html`, `project.html` и `README.md` оказались в корне, а `css`, `js` и `images` сохранили свои имена. Для публикации достаточно файлов из списка выше. Нажмите **Commit changes**. [Загрузка файлов через браузер](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)

Если загрузчик браузера разворачивает папки, воспользуйтесь Git из папки проекта. Эти команды предназначены для первого пуша в пустой репозиторий. Замените `ВАШ_ЛОГИН` и `goweb` на имя владельца и репозитория из адресной строки GitHub.

```bash
git init -b main
git add index.html projects.html project.html css js images README.md .nojekyll
git commit -m "Add GoWeb website"
git remote add origin https://github.com/ВАШ_ЛОГИН/goweb.git
git push -u origin main
```

### 3. Включите GitHub Pages

1. Откройте репозиторий, затем **Settings → Pages**.
2. В блоке **Build and deployment** в поле **Source** выберите **Deploy from a branch**.
3. В поле **Branch** выберите **main**, рядом укажите **/ (root)**.
4. Нажмите **Save**. [Настройка источника публикации](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

### 4. Найдите адрес сайта

После завершения публикации снова откройте **Settings → Pages** и нажмите **Visit site**. Адрес проекта обычно выглядит как `https://ВАШ_ЛОГИН.github.io/goweb/`. Если ссылки ещё нет, проверьте выполнение публикации во вкладке **Actions**. При дальнейших изменениях достаточно отправить коммит в `main`. [Публикация сайта GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)

## Добавление проекта

1. Откройте `js/projects.js` и добавьте объект в массив `PROJECTS` перед закрывающей `];`. Между объектами ставьте запятые.
2. Придумайте уникальный `id` из латинских букв, цифр и дефисов. Этот идентификатор используется в ссылке `project.html?id=demo-example`.
3. Для `category` используйте один из ключей `web`, `mobile`, `crm`, `ecommerce`, `ai`. Для концепции оставьте `demo: true`. Первые три элемента массива появляются также на главной.
4. Заполните поля по образцу. При отсутствии изображения можно указать `cover: ""`, а при отсутствии галереи `gallery: []`.

```js
{
  id: "demo-example",
  title: "Демонстрационный личный кабинет",
  category: "web",
  description: "Концепция кабинета с историей заявок.",
  tags: ["Личный кабинет", "Заявки"],
  cover: "images/demo-example.webp",
  demo: true,
  task: "Показать историю заявок пользователя.",
  work: ["Макет списка заявок", "Макет карточки заявки"],
  technologies: ["HTML", "CSS", "JavaScript"],
  result: "Макеты показывают переход от списка к деталям заявки.",
  gallery: [
    { src: "images/demo-example.webp", alt: "Список заявок в кабинете", caption: "История заявок" },
  ],
},
```

## Замена изображений, текстов и ссылок

- **Изображения.** Положите новые файлы в `images/`. Для главной обновите `src` у `.hero-image` в `index.html`. Для кейса измените `cover` и `gallery` в `js/projects.js`. В `alt` кратко опишите содержание каждого скриншота. Используйте путь вида `images/demo-example.webp` и соблюдайте регистр букв в имени файла.
- **Тексты.** Редактируйте главную и услуги в `index.html`, содержимое кейсов в `js/projects.js`, заголовки разделов кейса в `project.html`. Шапка и футер записаны в каждом из трёх HTML-файлов. Цвета заданы в начале `css/style.css`.
- **Контакты.** В начале `js/main.js` заполните объект `CONTACTS`. В `telegram` укажите публичное имя без `@`, в `whatsapp` номер с кодом страны, в `email` полный адрес. Эти значения применятся ко всем контактным ссылкам и кнопкам «Обсудить проект». До заполнения Telegram кнопки ведут в раздел контактов. После заполнения email форма откроет черновик через `mailto:` в настроенном почтовом клиенте посетителя. Отправка происходит только из этого клиента.
- **Демонстрационные иллюстрации.** Галерея показывает сгенерированные макеты интерфейсов для вымышленных сценариев. При добавлении реального проекта замените изображения, описание и результат на подтверждённые материалы.

После правок откройте главную, каталог и один из кейсов. Проверьте фильтры, переход по `?id=`, мобильное меню, пути к изображениям и черновик формы. Затем загрузите изменения в `main`.
